# Offline sample (realtime part is SYNTHETIC)

This folder lets CI, the Quickstart and the dbt tests run on a fresh clone with **no API key and
no network**. It is never used for findings.

| Part | Source |
|---|---|
| Timetable (`lake/raw/schedule/`) | **Real**: an unchanged slice of the DTP GTFS Schedule release `20261021_b1608bd3` (Alamein + Glen Waverley trains; tram routes 109 + 96). CC BY 4.0, Department of Transport and Planning. |
| Realtime (`lake/raw/realtime/`, `lake/raw/coverage/`) | **Synthetic**: simulated 60-second polls for Thu 22 Oct 2026 07:00-09:00 and Sat 24 Oct 2026 11:00-12:00, generated by `scripts/make_sample.py` (numpy seed 42). |

The simulation deliberately exercises the edge cases the pipeline must handle: cancelled trips,
trips never seen in the feed, tram trip updates without `start_date`, metro stops reported as the
parent station without `stop_sequence`, a 12-minute collector outage, a route-96 incident with a
matching service alert, delay-only vs absolute-time predictions, and stops dropping out of the feed
once passed. See `manifest.json` for the parameters.

Regenerate (needs a static snapshot in `data/lake`):

```bash
uv run python scripts/make_sample.py
```

Build the warehouse on it:

```bash
uv run python scripts/run_pipeline.py --sample
```
